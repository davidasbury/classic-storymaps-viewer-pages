## Learnings

- Browser image error events do not identify TLS, permissions, HTTP status or
  deletion reliably. The modal describes possible causes rather than presenting
  an unverified host diagnosis.
- This is not a universal network monitor: cross-origin embedded documents,
  CSS-only backgrounds without a supported native error state, and failures
  occurring only in detached probes are outside detection. Native story
  acceptance was performed for Map Tour, not all eight full story workflows.
- No automatic retry, HTTP fallback, proxy, archive lookup, source rewrite or
  security bypass was introduced. A slow recovery may finish after a notice
  has already appeared; the notice makes no permanent-unavailability claim.
