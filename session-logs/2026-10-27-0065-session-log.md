## Learnings

- Source lockfiles do not enumerate every browser-delivered library or SDK module.
- A scanner version match does not prove the affected optional widget or hostile
  input path is present. Unknown reachability must stay explicit.
- Matching a version literal alone is ambiguous inside a large release bundle;
  named AMD registration plus the original expression hash gives a narrow guard.
