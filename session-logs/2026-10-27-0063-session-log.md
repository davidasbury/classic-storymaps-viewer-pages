## Learnings

- A passing Pages build can use a pinned release and conceal source-toolchain
  breakage. Check both the actual tool APIs and emitted artifact identity.
- The npm `--prefix` invocation produced a spurious missing-root-package error
  in this environment; the exact Crowdsource PR installed from its package cwd.
- Keep overlapping dependency fixes together; replacing whole PR lockfiles
  sequentially would lose fixes from the other PR.
