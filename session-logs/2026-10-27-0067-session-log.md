## Learnings

- Passing through the expression is insufficient while the gallery still applies
  a literal title substring filter. Both the request builder and local acceptance
  path must distinguish the explicit mode.
- Advanced syntax cannot widen the selected gallery scope or bypass ArcGIS
  permissions. For another owner's public content, select ArcGIS Online before
  entering an owner expression.
