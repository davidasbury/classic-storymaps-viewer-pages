  Series, Cascade and Shortlist, with no page exceptions.

  extraction produced expected text without executing markup or requesting assets.

  checks, including long input. The subsequent print repair left viewer bytes

  GitHub resolution was not assumed before a fresh CodeQL analysis.

### Problems Encountered

- The first native Controller probe used the non-React AMD namespace. Inspection
  of the delivered registration identified the correct name, and both cases passed.
- Applying the print URL patch before the existing print adapter changed bytes
  that its checksum protects. The guard correctly rejected that ordering. Moving
  the patch after original-byte verification restored the checks without relaxing
  the checksum or sanitizer.
- Concurrent gallery work changed shared tracking and browser-test files. Security
  closure was scoped to this batch without reverting the gallery work.

## Learnings

- Detached jQuery fragments are not inert text parsers. HTML templates can provide
  text without activating parsed nodes when neither nodes nor fragments are inserted.
- A release patch must respect the order of pre-existing whole-artifact checks.
